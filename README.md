# 果果剧库

仅支持红果的本地短剧点播与下载工具，适用于 macOS、Windows 和 Linux。Go 标准库后端，原生 JavaScript 页面，无 npm、框架或 CDN 依赖；另提供基于 Wails 的桌面版，双击即用，详见 [桌面版说明](docs/desktop.md)。保留站源选择器，提供“全部站源”和“红果”，默认选中红果；支持站源、分类与关键词组合筛选。当前全部站源也只包含红果剧集。

本版本仅包含红果站源实现、配置和封面代理；读取缓存、恢复任务、点播和下载均校验红果来源。运行数据与原项目独立，请勿共用数据目录。

请仅观看或下载你拥有权利或已获授权的内容。在线播放、下载和合并需要本机 FFmpeg，详见 [FFmpeg 说明](bin/README.md)。

## 项目结构

```text
.
├── internal/
│   ├── app/              下载、点播、站源、剧库、配置和 HTTP 接口
│   └── webui/            原生 HTML、播放器脚本、样式及 Go 内嵌资源
├── desktop/              Wails 桌面版入口、启动页与图标
├── scripts/              跨平台构建、启动脚本
├── docs/                 使用指南
├── bin/                  可选的便携 FFmpeg
├── main.go               应用入口
├── go.mod
└── README.md
```

`internal/app` 按职责组织文件：`config_*` 管理配置，`provider_*` 对接站源，`library*` 管理剧库，`download*` 处理下载，`network_*` 处理网络，`ui_*` 提供管理接口，`desktop_picker*` 调用系统目录选择器。平台专属实现保留 Go 的文件名后缀约定。

页面源码位于 `internal/webui/index.html`，播放器、排序、榜单的脚本和样式在同一目录，全部通过 `go:embed` 编译进程序。修改后重新构建即可，不需要额外的前端构建步骤。业务实现留在内部包中，命令入口不承载业务逻辑。

`desktop/` 是桌面版入口：用 Wails v2 打开原生窗口，窗口内加载同一套本机服务与页面，`internal/app/desktop.go` 负责服务的启动与优雅关闭。命令行版可执行文件仍只包含标准库代码。

## 源码运行

需要 Go 1.25+。以下命令均在项目根目录执行：

```bash
go run .
```

默认监听 `0.0.0.0:8999`，本机自动打开 `http://127.0.0.1:8999`；同一局域网内的设备使用 `http://运行程序电脑的局域网IP:8999` 访问，并允许防火墙放行 TCP 8999 端口。`0.0.0.0` 是监听地址，不是其他设备的访问地址。

不自动打开浏览器时使用 `go run . -open=false`；仅限本机访问时使用 `go run . -listen 127.0.0.1:8999`。管理界面没有身份验证，请仅在可信局域网使用，不要把端口暴露到公网。全部参数见 `go run . -help`。

## 构建

macOS / Linux 构建四个平台版本：

```bash
./scripts/build.sh
```

Windows 在项目根目录执行 `scripts\build.bat`，构建 Windows x64 版本。构建产物统一放在 `dist/`，也可使用 `scripts/` 中对应系统的启动器。

桌面版：Windows 执行 `scripts\build-desktop.bat` 生成 `dist\果果剧库.exe`，macOS / Linux 执行 `./scripts/build-desktop.sh`。脚本会在缺少时自动安装 Wails CLI；产物为单个文件，双击即可使用，详见 [桌面版说明](docs/desktop.md)。

分发时只需对应平台的可执行文件，页面已经内嵌，无需附带源码或配置。更多平台与参数见 [使用指南](docs/usage.md)。

## 红果剧库与搜索

主目录使用红果 App 分类入口，包含真人剧、漫剧、AI 剧，保留网页回退。已有缓存先展示；“更新剧库”先检查新内容，再从保存的分页位置继续读取，重启后可以续载；首次导入只读取一批。每批按剧 ID 合并，保留未在本批返回的旧剧集。

输入关键词进行本地筛选，点击“联网搜索”或按回车补充红果站点返回的首批匹配。目录、搜索、榜单及下载使用同一剧 ID；App 参数与签名由 Go 生成，无需 Python、模拟器或外部签名服务。详见 [红果 App 接入说明](docs/hongguo-app.md)。

## 排序与真实榜单

筛选栏提供最新上线、最早上线、热度最高、播放最多和名称排序，本地及联网搜索结果都参与排序。“聚宝仙盆”的第二季至第十一季按自然季序排列；缺失字段置后，源站没有的日期、热度或播放量保留未知。

首次取得新条目时保留当前接口的全部可用排序字段；其他接口的数据在低优先级后台补齐，列表、搜索和榜单先返回。历史条目由“更新剧库”分批异步回填，每次最多 40 部，优先当前筛选结果；进度和结果保存在原有剧库缓存中，补齐后自动更新排序并保留勾选。

顶部导航里的“榜单”是一个独立页面，提供红果总热播榜、真人剧榜、漫剧榜和 AI 剧榜，按真实名次分页，可直接播放、下载。当前没有独立日、周、月周期榜。榜单仅展示文字；标题栏统一使用“更新剧库”，桌面端设置保留原位，小屏设置沿用“更多”菜单。详见 [排序与榜单说明](docs/rankings.md)。

## 封面显示

红果的签名 HEIC 封面由本机自动转换为 JPEG，兼容内置 FFmpeg。重复请求使用限额内存缓存，FFmpeg 准备完成后自动重试当前失败的封面。详见 [封面兼容说明](docs/covers.md)。

## 页面结构

顶部导航分为四页：“剧库”是首页，点击卡片封面或标题直接进入全页播放视图；“榜单”按源站真实名次列出各类榜单，可直接播放或加入下载；“观看历史”记录每部剧最近看到的分集与进度，可继续观看或删除；“下载”是二级页面，承载原来的下载合集列表、批量操作与合并。设置仍以弹窗形式从顶栏打开。

剧库卡片上的“↓ 下载”把单部剧加入下载队列；“批量下载”进入多选模式后出现勾选框与底部操作条，支持全选、反选与一次加入多部。看过的剧在封面底部显示“看到第 N 集 mm:ss”与进度条。

## 观看历史

播放器每 5 秒以及暂停、切集、离开时上报进度，保存在 `data/history.json`，按剧记录最近分集、位置，并为每一集单独记录进度与“已看完”标记。再次打开一部剧时自动从上次位置继续；上一集看完则直接播放下一集；选集按钮上显示各集的进度条与已看标记。历史页支持搜索、单条删除和清空，最多保留 300 部。接口为 `/api/ui/history` 与 `/api/ui/history/remove`。

## 在线点播

点击剧库卡片进入全页播放视图：左侧是深色剧场区，画面内有顶部图标条（上一集 / 下一集 / 倍速 / 清晰度 / 画中画 / 纯净模式 / 网页全屏 / 全屏）和底部控制条（进度条含缓冲区间、时间、播放暂停、音量）；右侧是选集与剧情简介，标题栏可一键“加入下载”。支持选集、进度跳转、倍速、暂停和自动下一集，不加入下载任务、不保存视频文件。

“小窗模式”（工具栏按钮、画面内图标或按 I）把剧场缩成悬浮小窗：按住顶部图标条拖动位置，拖右下角手柄按画面比例等比缩放，横屏与竖屏分别记住宽度，位置和开关状态也会记住；开着小窗可以切到剧库、历史、下载页面边看边逛，再点卡片会直接在小窗里播放。按 I、Esc 或小窗上的还原图标回到全页视图。

键盘快捷键：空格或 K 播放暂停，←/→ 快退快进 5 秒（Shift 为 30 秒），↑/↓ 调音量，M 静音，N/P 切集，F 全屏，W 网页全屏，I 小窗模式，Esc 逐层退出并返回。音量、静音、倍速、清晰度、自动连播和预缓存开关都会记住上次选择。取流失败时自动重试两次，加载与缓冲状态在画面上以遮罩提示。下载合集及展开的分集也有“播放”按钮：优先播放本地已完成文件，播到未完成分集时仅自动下载该集，不重复创建任务。点播使用 FFmpeg 实时转换为浏览器兼容格式，需要包含 `libx264` 和 AAC 编码器的完整版本。

播放器提供默认开启的“预缓存下一集”：当前集缓冲完成、临近结束时提前准备下一集，切集直接复用缓存。开关会记忆，只保留一个待播分集，关闭窗口即释放，不新增下载任务。详见 [预缓存说明](docs/playback-prefetch.md)。

红果播放已接入真实文字弹幕：工具栏提供记忆开关，随播放进度分段异步加载，支持暂停、倍速、跳转和全屏。滚动使用浏览器原生线性动画；弹幕失败不影响播放。普通评论暂未接入，详见 [弹幕说明](docs/playback-danmaku.md)。

未找到 FFmpeg 时自动下载并校验对应平台的便携版本，无需用户手动安装。进度与失败重试入口在界面内显示；已有 FFmpeg 保持不变，详见 [FFmpeg 说明](bin/README.md)。

## 运行数据

- `data/`：首次运行自动生成配置、剧库缓存、任务状态和观看历史（`history.json`），无需事先准备配置文件。
- `短剧下载/`：默认视频目录；支持在界面中调用系统文件夹选择器，也可使用 `-out` 指定其他目录。
- `dist/`：构建产物，不参与源码分发。

独立程序以所在目录为工作目录；源码运行和项目内 `dist/` 程序使用项目根目录。目录调整不改变原有配置格式、缓存、任务和下载路径规则。自定义路径、代理、站源与任务操作详见 [使用指南](docs/usage.md)。

## 同步维护

`juku` 多站源版与“果果剧库”红果专用版的通用功能及红果能力同步维护；专用版继续只允许红果，运行数据各自独立。后续修改范围和验证要求记录在两个项目各自的 [AGENTS.md](AGENTS.md)。同时运行时请指定不同监听端口。
