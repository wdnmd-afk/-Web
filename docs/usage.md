# 果果剧库使用指南

返回 [项目说明](../README.md)。本文源码相关命令均在项目根目录执行。

仅支持红果的本地点播和下载工具，使用 Go 标准库实现，支持 macOS、Windows、Linux。Web UI 使用原生 JavaScript 和 DOM API，不依赖 npm、框架或 CDN；在线播放、下载和合并需要本机 FFmpeg。

缺少 FFmpeg 时自动下载经过校验的便携版本，使用当前代理设置，无需手动安装。过程在后台进行，剧库仍可浏览；下载模块和设置弹窗显示进度及失败重试按钮。已有 FFmpeg 不会被覆盖；显式指定无效路径时需要更正配置。详情见 [FFmpeg 说明](../bin/README.md)。

请仅观看或下载你拥有权利或已获授权的内容。网站登录、付费、地域限制和上游服务故障不保证可用；只处理上游实际提供的媒体和密钥，不包含 DRM 许可证获取功能。

## 启动与升级

分发时只需对应平台的一个可执行文件，不需要附带配置、网页资源或启动脚本：

- Windows x64：双击 `juku_windows_amd64.exe`。
- Apple Silicon：使用 `juku_darwin_arm64`；Intel Mac 使用 `juku_darwin_amd64`。
- Linux x64：使用 `juku_linux_amd64`。
- macOS / Linux 进入程序所在目录运行对应文件，例如 Apple Silicon 执行 `./juku_darwin_arm64`。程序会自动打开浏览器；服务器环境可在命令后添加 `-open=false`。

**升级后需要先自行退出旧下载器，再替换程序、启动新版并刷新浏览器。** 保留自己的 `data/` 和下载目录。程序不会杀死占用端口的其他进程。

默认监听 `0.0.0.0:8999`，本机访问地址为 `http://127.0.0.1:8999`。同一局域网内的设备使用 `http://运行程序电脑的局域网IP:8999` 访问；如果无法连接，请确认设备处于同一局域网、没有无线客户端隔离，并允许防火墙放行 TCP 8999 端口。`0.0.0.0` 仅表示监听所有 IPv4 网络接口，不是浏览器访问地址。

独立程序默认以可执行文件所在目录作为工作目录；请将程序放在可写目录中运行。

首次启动自动生成 `./data/juku.json`；配置、缓存和任务状态均存放于 `./data/`，没有配置文件也能启动。Web UI 中只显示中文名称“果果剧库”。

源码项目构建后也可用 `scripts/` 中的相对路径启动器：macOS 双击 `scripts/启动剧库.command`，Windows 使用 `scripts\启动剧库.bat`，Linux 使用 `./scripts/启动剧库.sh`。例如在源码根目录运行 Intel macOS 构建：

```bash
./dist/juku_darwin_amd64
```

通常无需手动安装 FFmpeg；自动准备失败或需要自选版本时，可手动安装：

```bash
brew install ffmpeg
```

Linux 可用 `sudo apt install ffmpeg`。Windows 可把 `ffmpeg.exe` 放进 `./bin/`，或将其目录加入 PATH。macOS / Linux 也支持 `./bin/ffmpeg`。可通过 `-ffmpeg ./bin/ffmpeg.exe` 等相对路径指定程序。编译后的程序不需要 Go、Node.js 或 Python；**分发一个程序即可，首次运行缺少 FFmpeg 时联网自动准备**，离线环境需事先提供 FFmpeg。

源码启动需要 Go 1.21+：

```bash
go run .
go run . -open=false -listen 0.0.0.0:8998
go run . -out ./短剧下载 -c 3
```

默认允许局域网访问；`-listen :8998` 也会监听所有 IPv4 网络接口。仅限本机使用时，执行 `go run . -listen 127.0.0.1:8999`。

管理界面没有身份验证，同网段设备可以操作下载、任务和设置。请仅在可信局域网使用，通过防火墙限制访问，不要将端口映射或暴露到公网。远程操作的下载文件和路径均属于运行程序的电脑，不会保存到访问页面的设备；系统文件夹选择器仍仅允许本机使用。

### 自定义下载目录

所有系统默认下载到 `./短剧下载`，不依赖固定盘符、用户名或机器目录。支持包含空格和中文的路径，支持相对或绝对路径：

- Web UI：打开“代理 / 设置”，点击“选择文件夹”，直接弹出系统原生文件夹选择窗口；选中后自动填回路径，取消不修改原目录。也可直接填写路径。保存后重启生效。
- 命令行：`go run . -out "./我的下载/短剧"`；Windows 编译版可用 `dist\juku_windows_amd64.exe -out ".\我的下载\短剧"`。
- 配置文件：通常无需手改；对应项为自动生成的 `data/juku.json` 中的 `download.directory`。
- 环境变量：`JUKU_OUTPUT_DIR`，显式 `-out` 参数优先级最高。

文件夹选择使用系统窗口，不在网页内列出目录。macOS 调用系统 `NSOpenPanel`；Windows 调用系统文件夹对话框，使用内置 Windows PowerShell，无需另外安装组件。Linux 桌面需要 `zenity` 或 `kdialog`。选择期间不阻塞剧库和下载任务，也不会重复打开多个窗口。

系统窗口属于**运行程序的电脑**，仅允许从本机 `localhost` / 回环地址界面发起，不是上传浏览器电脑的文件。远程访问、无桌面或系统工具不可用时仍可手动输入路径。相对路径以程序工作目录为基准：独立分发版为程序所在目录，源码构建的 `dist/` 程序为项目根目录。显式使用 `-data-dir` 或 `-config` 时保留调用者的工作目录，方便脚本指定相对路径。

修改目录会先检查可写性，**不会移动、删除或重定向当前任务**。重启后新合集使用新目录；已有合集的任务、更新和合并继续使用原路径。缓存和任务记录仍在同一个 `data/` 中，不随视频目录切换。如果一直携带 `-out` 启动，该参数会覆盖界面保存的目录。

## 自动配置与数据目录

默认不再需要根目录的 `config.json`、配置示例或单独的界面设置文件。站点地址、协议参数等通用默认值内置于代码；首次运行仅生成常用设置：

```json
{
  "version": 1,
  "download": {
    "directory": "短剧下载",
    "concurrency": 2
  },
  "network": {
    "proxy": "auto",
    "requestConcurrency": 2,
    "requestIntervalMs": 500
  }
}
```

需要覆盖红果入口时，同样只使用这一份文件；没有覆盖需求时这些字段不会出现在默认配置中：

| 可选字段 | 对应站源 / 用途 |
| --- | --- |
| `sources.hongguo.baseURL` | 红果入口 |
| `download.ffmpeg` | 自定义 FFmpeg 路径 |
| `advanced` | 可选的页数、重试次数等高级覆盖，通常无需修改 |

红果入口和协议默认值内置，通常无需配置。界面保存常用设置时保留红果入口覆盖项。

首次升级自动导入旧 `config.json`、`juku-settings.json` 或旧下载目录的 `settings.json`，并将旧的 `library.json`、`ui-state.json`、`failed.json` 复制到 `data/`。已有新数据不被覆盖，旧文件保留以便回退；后续启动只读取新配置，不会反复导入旧任务。配置损坏时明确报错，不静默覆盖。

启动时配置优先级：内置默认值 < `data/juku.json` < `JUKU_*` 环境变量 < 显式 CLI 参数。可用 `-data-dir ./其他数据目录` 指定统一的数据位置。配置可能含有凭证，分享程序时请勿附带自己的 `data/` 目录或旧配置文件。

## 剧库

- 只加载红果站源，App 主目录包含真人剧、漫剧、AI 剧，保留网页分类回退；站源筛选栏只有“全部站源”和“红果”。
- 默认站源为“红果”，分类为“全部分类”，关键词为空，显示所有已加载的红果剧集。“全部站源”的值为空字符串，表示不过滤；当前版本仍只会展示红果。
- 关键词、站源和分类可组合筛选，数量与内容立即更新。切换站源时重新生成分类选项并重置为“全部分类”；筛选本身不访问远端站点。
- 已有缓存时先展示本地数据，点击“更新剧库”才更新目录；首次没有缓存时在后台加载，结果分批显示。
- 每批按剧 ID 合并，成功更新也保留未在本批返回的旧剧。“更新剧库”先检查最新至多 3 页（同时不超过配置的单批页数），遇到整页已知内容提前停止，再从保存位置继续读取历史；新内容较多时接着读下一未读页。首次导入只读取一批，重启后可续载；`-pages` 控制 App 每个频道首次读取和历史续载的单批页数，默认 20，安全上限 200，不代表资源总页数上限。
- 点击“联网搜索”或按回车补充红果站点的首批匹配，输入关键词时仍只做本地筛选。
- 缓存、历史任务、下载和更新请求均检查红果来源，不会恢复其他来源的剧集。请为本版本使用独立数据目录。
- 剧库与下载合集各自独立滚动，更新时间显示在剧库标题旁；前端不显示站源抓取报错。

## 排序与站点榜单

筛选栏可按最新 / 最早上线、热度、播放量、名称排序；本地及联网搜索结果统一参与比较，并记住上次选择。“第二季、第三季……第十季”按自然数字顺序排列。缺失字段置后，全缺失时保留原顺序并提示；不把创建时间、抓取时间当上线日期，不把播放量或评分当热度。

新条目先返回主接口全部可用字段，其他接口资料后台异步补齐；旧缓存点击“更新剧库”才分批补齐，每批最多 40 部，优先当前筛选结果，同时检查上新并继续未完成的红果目录。普通读取、页面重载和切换排序不主动迁移旧缓存。目录和资料均已处理后，按钮仍可再次检查上新；主目录更新期间防止重复点击，后台补资料期间保持可用。补齐不阻塞列表、搜索和榜单，后台进度自动更新，排序与勾选状态保留；源站确实没有的字段保持未知。

“榜单”位于剧库标题旁，弹窗内提供红果总热播、真人剧、漫剧、AI 剧四种真实榜单，支持分页、播放和下载。名次以源站为准，站点未提供的日、周、月榜不伪造；失败时可显示有标记的旧结果。榜单仅使用文字列表。

标题栏统一保留“更新剧库”入口。桌面端“代理 / 设置”保留原位；小屏设置和更新时间收纳到现有“更多”菜单，更新、排序和榜单仍可直接操作。接口和补齐规则见 [榜单说明](rankings.md)，目录、搜索和取流见 [红果 App 接入](hongguo-app.md)。

## 下载合集

- 合集和分集都可勾选；全选、反选针对当前筛选结果，另有取消勾选。
- 可按已完成、失败、未完成、进行中、暂停、取消过滤，也可按完结、未完结、状态未知过滤。
- “完结”来自网站提供的更新状态，**不会把本地下载完成误当作剧情完结**。
- 每部合集支持暂停、继续、取消、重试失败、更新、合并。合集操作在后端按剧 ID 确定当前分集，避免刚解析出的分集被漏掉。
- 批量操作收纳在“批量操作”菜单内。暂停、继续、取消、重试针对所选分集；更新和合并针对这些分集所属的合集。
- **“清理任务”只清理勾选的任务记录，不删除已下载视频。** 正在运行或解析的任务会先停止，再移除记录。
- 暂停、取消保留其他已完成分集。继续时重新下载当前未完成分集，不是分片或字节级断点续传。
- 重启后保留暂停状态；运行中断的下载恢复排队，章节解析中断则可以重试。

### 更新与合并

“更新本剧”重新获取章节，只补充新增或本地缺失的分集；失败或取消的任务可用“重试失败”重新排队并解析新播放地址。

合并要求分集连续且文件存在。输出按范围命名，例如 `短剧名1-17.mp4`；追更后可生成 `短剧名1-18.mp4`。相同范围的有效合并文件会跳过。

“合并成功后删除分集文件”默认关闭；只有用户主动启用，且合并输出校验成功后才删除分集。它与“清理任务”是完全不同的操作。

## 代理与并发设置

点击剧库标题栏的 **“代理 / 设置”** 打开弹窗。设置统一保存到 `data/juku.json`，代理和并发立即生效，下载目录重启生效。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 下载并发 | 2 | 可修改，范围 1–32；降低后不强制中断正在下载的分集 |
| 剧库请求并发 | 2 | 可修改，范围 1–16；同一站源的元数据请求保持串行 |
| 同站请求间隔 | 500 毫秒 | 可修改，范围 100–60000 毫秒；不对视频分片套用此间隔 |
| 代理模式 | 自动 | 环境变量代理优先，然后读取 macOS / Windows 系统静态代理；没有代理则直连 |

也可选择直连，或手动填写 HTTP、HTTPS、SOCKS5 / SOCKS5h 代理。用户名、密码可分开填写。Linux 自动模式读取环境变量；暂不解析 PAC 脚本。

自动模式识别的是代理地址，**不代表代理软件的当前节点或分流规则一定可用**。切换了系统代理后，可以重新保存自动模式以重新检测。代理变更用于后续连接，不强行中断正在传输的连接。

FFmpeg 的播放列表、密钥、分片和 MP4 请求统一经过本地 Go 转发，所以下载与站点请求使用同一套代理设置。代理账号密码不通过配置查询回显，日志中的 URL 认证信息和签名参数会隐藏。`data/juku.json` 在支持权限的系统上以仅当前用户可读写的权限保存，但不是加密存储，请勿分享它。

“检测当前连接”检查红果入口、封面，以及已有红果任务的播放地址和首个媒体资源。入口可达不等于下载可用；检测本身也不等于整集下载验证。

## 进度与文件

解析、排队、暂停不伪造下载进度。下载开始为 0%；有媒体总时长时根据 FFmpeg 实际处理时长估算，否则显示未知进度。未完成文件校验和重命名之前不显示 100%。速度按临时文件实际增长计算，未知总大小和剩余时间显示 `—`。

```text
data/
├── juku.json             唯一配置文件，首次运行生成
├── library.json          剧库缓存，加载后生成
├── ui-state.json         下载、暂停和合并状态
└── failed.json           CLI 模式的失败记录（按需生成）
短剧下载/                  可自定义，与数据目录独立
└── 短剧名/
    ├── .drama-id
    ├── 001.mp4
    ├── 002.mp4
    └── 短剧名1-2.mp4
```

下载过程使用 `.part.mp4`，成功后才生成最终文件。同名但来源/ID 不同的短剧使用不同目录，避免覆盖。旧版嵌入任务状态的剧库会迁移到独立缓存。

更换下载目录不会清空缓存或任务。不要提交或公开 Token、接口密钥和签名播放 URL。

## 红果后续分集

红果官网部分剧集的 `accessible_episode_cnt` 仅为 3：详情虽然列出全集 ID，但第四集起的网页播放器会返回 404。这不是下载并发过高，也不能通过反复刷新剧库解决。

程序先用 App 详情取得完整分集，并优先用 App 接口选择兼容的最高画质。App 失败后回退官网播放器，再按原剧 ID、分集 ID 调用已有备用播放接口 `djapi.999888456.xyz/api/hongguo/play`，选择可用的最高画质，并将接口返回的逐集密钥交给 FFmpeg 解密、封装为普通 MP4。不会把前三集的试看地址冒充后续分集。

备用接口来自参考脚本的独立上游服务，仅向其发送剧集 ID，不发送本地配置、任务文件或站点凭证；可用性仍取决于该服务。网络请求继续使用界面中保存的代理设置，无需 Python、Android 组件或额外配置文件。播放链接和密钥只在当次取流期间使用，不写入任务记录；重试会重新取流。

已有失败任务可在退出旧程序、启动新版后直接“重试失败”，无需清空记录或重新添加合集。下载目录和已成功的分集保持不变。

## 不同编码的分集合并

合并前通过现有 FFmpeg 检查各集的视频编码、分辨率、时间基准和音频参数，不额外依赖 `ffprobe`。参数完全一致时保持原编码快速合并；如果前三集为 H.264、后续为 HEVC，或 AAC 音频参数不同，则逐集统一转换为 H.264 / AAC 后再合并，避免直接拼接造成封装报错或后续黑屏、无声。

兼容合并使用各集的最大画布尺寸，保留画面比例并补边，统一为 30 帧；有声与无声分集混合时自动补充静音。此模式需要包含 `libx264` 和 AAC 编码器的完整 FFmpeg，比原编码合并更耗时，也需要额外临时磁盘空间，画面会重新编码。界面显示检测、转换分集数量及实际处理进度，不再固定跳到 35%。

转换文件只写入临时目录，结束后自动清理。只有封装成功、时长核对通过后才生成最终合集；失败时保留全部原分集。默认不删除分集，只有用户明确选择合并后删除，才会在成功后删除原分集。

## 在线点播

点击剧库卡片上的“在线观看”，无需勾选或加入下载队列。播放器独立弹出，原来的剧库筛选、下载任务和两栏滚动保持不变。

- 支持选集、上一集 / 下一集、暂停、音量、全屏和倍速；可关闭“自动下一集”。选集按钮保持完整高度，长列表独立滚动，不挤压按钮文字。
- 拖动播放器进度条即可跳转。已缓冲位置直接播放，未缓冲位置会重新取流，显示“正在跳转并缓冲”。
- 失败时在播放器内部显示原因；“重试播放”重新解析地址并尽量从当前进度继续，不会生成下载任务。
- 使用界面中保存的代理设置和红果取流逻辑，保留后续分集的备用接口。
- 后端通过 FFmpeg 的标准输出实时发送分片 MP4，浏览器用原生 MediaSource 播放。为兼容 HEVC、加密 MP4 和 HLS，在线画面转换为 H.264 / AAC，最高 720p、30 帧；下载仍保留原来的处理方式。
- **从剧库“在线观看”不保存视频到下载目录，不生成播放记录或新配置文件。** 仅在内存中保留播放缓冲和临时会话；关闭播放器、切集或页面离开时中止旧取流。异常断开的会话在停止心跳约两分钟后释放，最多同时保留四个播放窗口，避免遗留转码进程。

需要完整 FFmpeg（包含 `libx264`、AAC 编码器），无需额外安装播放器库、Node.js 或 `ffprobe`。建议使用当前版桌面 Chrome、Edge、Firefox 或 Safari；不支持原生 MediaSource 的浏览器会提示更换浏览器。浏览器禁止自动播放时，点击视频中的播放按钮即可。实时转换会占用运行程序电脑的 CPU 和网络，首次缓冲及跨进度跳转可能需要数秒。

在线点播不会绕过登录、付费或其他上游限制；站点或备用接口不可用时仍可能失败。

### 红果弹幕

红果分集默认显示弹幕，工具栏内可关闭，选择会保存在当前浏览器。文字跟随视频的原始时间出现，暂停、缓冲、倍速和跳转时同步；使用工具栏“全屏”可保留弹幕叠加。数据按时间段独立加载，失败不影响观看，关闭后重新开启可重试。源站可能限制每段数量，当前段为空也会继续读取后续段。普通评论尚未接入；其他站源暂不显示弹幕开关。

播放器同时提供默认开启的“预缓存下一集”。当前集缓冲完成且临近结束时，后台提前取流和转码；切集复用结果，每窗口只缓存下一集，最多约 32 MiB，不保存视频文件或新增下载任务。开关会记忆，关闭播放器会释放缓存。详见 [预缓存说明](playback-prefetch.md)。

升级后退出旧程序，重新执行 `go run .` 并刷新页面。详见 [弹幕接口和验证说明](playback-danmaku.md)。

### 从下载合集播放

合集顶部的“播放”从合集第一条可播放分集开始；展开合集后，每集的“播放”直接定位到该集，之后仍可选集或自动连播。分集顺序按集数排列，不受勾选、任务状态筛选影响；尚未解析出章节的占位任务不提供播放按钮。

- 已完成且文件存在：直接读取本地 MP4，无需访问站点或重新下载，断网也可观看。仍通过本机 FFmpeg 转换为浏览器兼容格式，因此 HEVC 文件也能播放。
- 未完成或本地文件已丢失：播到该集时恢复/重试原下载任务，同时在线缓冲播放，不等待整集下载结束。已排队或正在下载的任务不会重复创建或重置。
- 仅触发当前选中或自动连播到的分集，不会因打开播放器就重启整部合集；其余暂停、失败、取消的分集保持原状态。原本已在下载队列里的其他任务仍按原规则运行。
- 拖动同一集的进度条不会反复重启下载；未完成的 `.part.mp4` 不作为已完成视频读取。
- 关闭播放器只停止播放，已触发的下载继续，可在下载合集中暂停或取消。清理掉的任务不会通过旧播放会话重新创建。

从剧库“在线观看”仍为纯观看模式，不自动下载；两种入口在播放器底部明确说明各自行为。

## 命令行

UI 是默认模式。CLI 模式请显式添加 `-ui=false`：

```bash
go run . -ui=false -mode list
go run . -ui=false -mode list -refresh
go run . -ui=false -mode list -more
go run . -ui=false -mode search -keyword 关键词
go run . -ui=false -mode id -id 'hongguo:7670772535931178008'
```

`-mode all` 下载当前剧库中的全部条目，可能产生大量任务和磁盘占用，请谨慎使用。

常用参数：`-data-dir ./data`、`-out 目录`、`-c 并发数`、`-pages 页数`、`-ffmpeg 路径`、`-listen 地址`、`-open=false`。`-config ./旧配置.json` 仅用于首次导入旧格式；日常无需此参数。`-refresh` 用于 CLI 强制检查新内容，`-more` 从保存的红果分页位置继续；二者不能同时使用。CLI 命令会等待本次工作完成，Web UI 的额外资料补齐在独立后台队列中执行。`-help` 查看帮助。TLS 校验默认启用，不建议使用兼容参数 `-insecure-tls`。

## 编译与分发

```bash
go build -o dist/juku .
./scripts/build.sh
```

`scripts/build.sh` 生成 `dist/juku_darwin_amd64`、`dist/juku_darwin_arm64`、`dist/juku_linux_amd64`、`dist/juku_windows_amd64.exe`。编译无需安装第三方 Go 依赖；页面资源会自动嵌入程序，不需要单独部署网页文件。

Windows 可使用 `scripts\build.bat` 仅编译 Windows x64 版本。当前验证环境为 macOS：Windows 原生 EXE 已交叉编译，但未在真实 Windows 设备上执行端到端测试。

构建后直接分发 `dist/` 中对应平台的可执行文件即可，无需预先生成配置文件。请勿附带自己的 `data/`、旧配置、任务记录、剧库缓存或已下载视频。FFmpeg 缺失时会自动准备，也支持手动提供，详见 [FFmpeg 说明](../bin/README.md)。所有构建和启动脚本均使用相对路径，不依赖开发机器的目录。

红果站点和备用接口由第三方提供，可能随时变化。入口连通或首个媒体资源可读不等于整集验证；播放与下载仍受上游访问权限、接口可用性及网络环境影响。
